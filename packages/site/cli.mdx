# Command line

seemore needs [Node.js](https://nodejs.org) 22 or newer. Run it in your folder of Markdown files:

Open the address it prints, `http://localhost:4040` by default. This is the [live preview](./live-preview.md): add, rename, retitle or delete a file, and the site updates at once, navigation and search included. You can also double-click any block on the page to edit its Markdown in place.

`npx` runs seemore without adding it to your project, and the preview writes nothing into your folder unless you save an inline edit.

## Common options

```bash
npx seemore docs          # serve a subfolder instead of the current folder
npx seemore --port 3000   # use another port
npx seemore --open        # open a browser tab on start
npx seemore --host        # make the preview reachable from other devices on your network
```

## Build and export

```bash
npx seemore build                 # build a static site into dist/
npx seemore export notes/plan.md  # write plan.html, one self-contained file, next to the Markdown
```

[Publishing](./publishing.mdx) covers hosting the build, base paths and password protection. The [CLI reference](./cli-reference.md) lists every command and flag.

## Add it to a project

For docs that live in a repository, add seemore as a dev dependency so everyone uses the same version:

```bash
npm install --save-dev seemore
```

```json title="package.json"
{
  "scripts": {
    "docs": "seemore docs",
    "docs:build": "seemore build docs"
  }
}
```

Then `npm run docs` starts the preview and `npm run docs:build` writes `dist/`.
