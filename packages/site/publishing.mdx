# Publishing

<CodeBlockTabs defaultValue="npm">
  <CodeBlockTabsList>

npx seemore build  # static export to dist/ for any host
```

```

  </CodeBlockTab>
  <CodeBlockTab value="bun">

```bash
bunx seemore build  # static export to dist/ for any host
```

  </CodeBlockTab>
</CodeBlockTabs>

The result is a `dist/` folder of plain web files: drop it on [Netlify](https://netlify.com), [Surge](https://surge.sh), [Cloudflare Pages](https://pages.cloudflare.com) or [GitHub Pages](https://pages.github.com), or hand it to any web host. Every page is prerendered to its own `index.html`, next to a `404.html` that every static host honours. The host-specific files are written for you too: `_redirects` for Netlify and Cloudflare Pages, `200.html` for Surge, `.nojekyll` for GitHub Pages.

> [!TIP]
> Publishing to GitHub Pages? Your site lives at `username.github.io/my-repo/` rather than the root, so tell seemore the subpath once with `base: '/my-repo/'` (or `--base /my-repo/` on the CLI). If you forget, the build prints the exact line to add.

This site is built exactly this way. See its [`seemore.config.ts`](https://github.com/arifszn/seemore/blob/main/packages/site/seemore.config.ts) and the [features](./features.md) page for what publishing gets you by default.
