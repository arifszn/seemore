## How it's different

</div>

<div className="seemore-uses seemore-uses--trio">

<div className="seemore-use">
  <span className="seemore-use-title">Starts where your files already are</span>
  <span className="seemore-use-desc">Most docs frameworks want a project: a scaffold, a config file, a docs/ layout, a build step wired into your repo. seemore wants a folder that already exists.</span>
</div>

<div className="seemore-use">
  <span className="seemore-use-title">Preview first, site generator second</span>
  <span className="seemore-use-desc">The same content serves locally, renders beside your editor, and builds to static HTML, with no separate setup for each.</span>
</div>

<div className="seemore-use">
  <span className="seemore-use-title">Nothing to migrate, nothing to undo</span>
  <span className="seemore-use-desc">Your files are never moved or rewritten, so walking away costs nothing.</span>
</div>

</div>
